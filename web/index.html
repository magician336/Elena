Elena

Append-only embedded storage engine in the Bitcask model, written in pure Go, with trajectory, session-TTL, and checkpoint semantics — the durable backbone for agent runtimes.

Fsync tiers, merge, and a kill - 9 recovery rig in CI; P99-first benchmarks against bbolt, badger, and rosedb from one declared environment. This page is fully static — it opens straight off the disk, no server, no build step. The two stories below were generated by driving the public library API with a fixed seed and an injected clock (go run ./cmd/webgen); the measured numbers were distilled from the raw benchmark JSON checked into the repository. Same input, same bytes, every time.

Act 1 Trajectory timeline

One session, six appended events, one point-in-time read. Every append hands out the next sequence number — monotonic, hole-free — and every event is immutable once acknowledged. The read stops at a known consistent sequence number and returns exactly the trajectory as of that point.

Sessions of this shape suit agent trajectory streams — one appended event per exchange, read back to any consistent point.

Act 2 Checkpoint recovery

A working session, an event group with its baseline checkpoint committed as one atomic unit, work that continues past the baseline, an interruption, and a reopen that restores to the baseline and resumes. The closing contrast is the restore boundary itself: the point-in-time read stops at the baseline, while the full read still shows every event on disk.

Checkpoints of this shape suit agent sessions that must resume from a known consistent point after an interruption.

Act 3 Measured, declared, reproducible

Every number below is distilled from the raw benchmark JSON in docs/benchmarks/data/ — one declared single-machine environment (NVMe/btrfs, one run per cell, P50/P99/P999 by nearest rank, no averages). Cross-engine numbers exist only inside aligned durability tiers; where elena loses, it is reported with the structural reason. Full report and reproduction commands: docs/benchmarks/README.md.
